# 공식 문서와 응답 차이점

이 문서는 직접 테스트한 [Json 성공 응답](Json%20성공%20응답%20목록.md)과 공식문서를 비교한 문서입니다.

### API Scope 이름
개발자 센터의 Scope 목록과 토큰 응답의 `scope` 기준.
- User 개요의 Scope가 `유저 정보 조회`로 적혀 있으나, 실제 이름은 `유저 조회`.
- Channel 개요의 Scope에 `채널 팔로워 조회`, `채널 구독자 조회`가 적혀 있으나 이런 Scope는 없음.
  - 팔로워·구독자 조회는 `채널 정보 조회` Scope에 포함됨. ("채널 정보(팔로워, 구독자 등)를 조회할 수 있습니다.")
  - 반대로 Channel 개요에는 `채널 정보 조회` Scope가 빠져 있음. (채널 정보 조회 API 자체는 Client 인증)

- `scope : String` 누락
- `expiresIn` 타입 명세 오류 (`String` → `Integer`)

### 치지직 Access Token 갱신
- `expiresIn` 타입 명세 오류 (`String` → `Integer`)

## Session

### 세션 목록 조회(클라이언트), 세션 목록 조회(유저)
- `page : Integer` 누락
- `totalCount : Integer` 누락
- `totalPages : Integer` 누락

### 구독 이벤트 메시지(채팅 이벤트 메시지)
- `eventSentAt : String` 누락
> "2026-05-21T12:10:24.651197398"
- `userRoleCode` 위치 오류: `profile` 내부 요소
- `badges` 상세 명세 누락 
> `{ "imageUrl": String }`이 확인됨.

## User

### 유저 정보 조회
- `nickname : String` 누락.

## Channel

### 채널 정보 조회
- `verifiedMarkType : String` 누락
- `officialChannel : Boolean` 누락

### 채널 관리자 조회
- `userRole`에 명세에 없는 `STREAMER`가 반환

### 채널 팔로워 조회, 채널 구독자 조회
- `page : Integer` 누락
- `totalCount : Integer` 누락
- `totalPages : Integer` 누락

## Chat
### Chat 개요의 API Scope 목록
- `채팅 메시지 조회`가 Chat의 Scope로 적혀 있으나 이 Scope를 쓰는 Chat API는 없음. 실제로는 Session의 이벤트 구독(채팅)에서 쓰는 Scope.
- 반대로 `채팅 메시지 숨기기`는 개요의 기능 목록에 빠져 있음. (Scope는 `채팅 메시지 쓰기`)

### 채팅 설정 변경
- 응답 명세 누락 : `채팅 설정 조회`와 같은 응답이 변경사항이 적용된 상태로 반환됨.
